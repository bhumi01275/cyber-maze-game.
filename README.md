# Cyber Maze Escape

A neon-themed maze game built with React + Vite. Includes keyboard and touch controls, levels, timer, move counter, personal best, and installable PWA support.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

## Install on your phone

1. Deploy the project to an HTTPS host such as Vercel or Netlify.
2. Open the deployed URL in Chrome (Android) or Safari (iPhone).
3. Android: use the browser's Install app / Add to Home screen option.
4. iPhone: Share → Add to Home Screen.

PWA install prompts require a supported browser and a secure HTTPS deployment (localhost is also treated as secure for development).

## Controls

- Keyboard: Arrow keys or WASD
- Mobile: on-screen directional pad
- Reach the pink exit tile to clear a level.
